# Журнал проблем и затруднений

## 2026-10-26 16:12 +03:00 — Запуск интеграционных тестов блокируется на restore

- **Задача / контекст:** Проверка сценарного покрытия и запуск интеграционных тестов .NET 10.

- **Что произошло:** Рекомендованная команда `dotnet test --project tests/Texnokaktus.ProgOlymp.ResultService.IntegrationTests/Texnokaktus.ProgOlymp.ResultService.IntegrationTests.csproj --verbosity normal` завершилась на restore с кодом 1, сообщив 0 ошибок и не показав причину. Отдельный последовательный restore выявил NU1902 и NU1903 для транзитивного пакета `System.Security.Cryptography.Pkcs` 9.0.11; предупреждения считаются ошибками.

- **Предпринятые попытки:** Выполнен `dotnet restore tests/Texnokaktus.ProgOlymp.ResultService.IntegrationTests/Texnokaktus.ProgOlymp.ResultService.IntegrationTests.csproj --disable-parallel -v minimal -p:BuildInParallel=false -m:1`, который вывел конкретные диагностические сообщения.

- **Решение:** Причина найдена; запуск тестов остаётся заблокированным. Зависимости и правила обработки предупреждений в рамках проверки покрытия не изменялись.

- **Предполагаемая первопричина:** Факт: restore отклоняет указанную версию пакета из-за результатов NuGet audit. Предположение: параллельное выполнение MSBuild скрывает полезную диагностику первоначальной команды.

- **Предлагаемое улучшение:** Отдельной задачей обновить зависимость, приносящую пакет; документировать последовательный restore как способ диагностики немого сбоя `dotnet test`.

## 2026-10-26 16:29 +03:00 — Microsoft.Testing.Platform не подключается к named pipe в песочнице

- **Задача / контекст:** Запуск расширенного набора интеграционных gRPC-тестов после успешной сборки.

- **Что произошло:** `dotnet test --project ... --no-build` завершился до выполнения тестов: `UnauthorizedAccessException` при `NamedPipeClientStream.TryConnect`, ошибка IPC handshake.

- **Предпринятые попытки:** Прочитана справка собранного тестового приложения и выполнен прямой запуск DLL через `dotnet`.

- **Решение:** Прямой запуск `dotnet tests/Texnokaktus.ProgOlymp.ResultService.IntegrationTests/bin/Debug/net10.0/Texnokaktus.ProgOlymp.ResultService.IntegrationTests.dll --no-ansi --progress off` успешно начал выполнение тестов без IPC с `dotnet test`.

- **Предполагаемая первопричина:** Ограничения доступа к именованным каналам в текущей Windows-песочнице; точная причина ограничения не установлена.

- **Предлагаемое улучшение:** Документировать прямой запуск собранного тестового приложения как альтернативу при отказе IPC.

## 2026-10-26 16:29 +03:00 — Windows EventLog маскирует ошибки интеграционных тестов

- **Задача / контекст:** Прямой запуск интеграционных тестов на Windows.

- **Что произошло:** Значительная часть тестов упала с ошибкой логгера: нет доступа к журналу источника `.NET Runtime`. Исключение логирования скрывает исходную ошибку обработки gRPC-запроса.

- **Предпринятые попытки:** Изучены стеки исключений и настройка логирования в `CustomWebApplicationFactory`.

- **Решение:** Для тестового хоста выбрано консольное логирование вместо системных провайдеров; результат будет проверен повторным запуском.

- **Предполагаемая первопричина:** Тестовый хост наследует Windows EventLog provider, требующий недоступных в песочнице разрешений.

- **Предлагаемое улучшение:** В тестовом хосте явно задавать переносимый провайдер логирования, не требующий доступа к системному журналу.
